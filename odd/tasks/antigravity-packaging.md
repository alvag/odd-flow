# Antigravity packaging

Objective: package the shared odd-flow skill and startup context as a native Antigravity CLI plugin.
Branch: `feature/antigravity-packaging`. Delivery: verify the package locally without installing it; runner: `bash tests/run.sh`.
Profile: `gpt-claude`.

## Specs

- S1 (user, verbatim): “continua con el empaquetado para Antigravity”. Target the installed `agy` CLI 1.5.16. Provide a native `.antigravity-plugin/plugin.json` and root `hooks.json`, reusing the default `skills/odd-flow` discovery and leaving Claude and Codex manifests unchanged.
- S2 (startup): Register only a flat `SessionStart` command with a relative path. Reuse the shared core blocks and `profile.py` through the startup adapter. Read Antigravity `conversationId`, make it the `ANTIGRAVITY_CONVERSATION_ID` for profile resolution without an inherited Claude or Codex ID taking precedence, and emit Antigravity's `injectSteps` with the nested `systemMessage`. Preserve the existing mode fallback and non-blocking behavior; return a valid Antigravity JSON response on malformed input or resolution errors. Preserve the existing Claude and Codex startup behavior.
- S3 (scope): Document standalone CLI validation and local install instructions, distinguishing validation, hook fixtures, and future installed-session smoke tests. No install, migration of active settings, trust changes, credentials for Antigravity, or marketplace publication in this delivery. `PreInvocation`, `PreToolUse`, mid-session mode reinjection, actual profile identity in interactive `agy`, and Antigravity Orca worker enforcement are not validated or promised by this package. Do not copy Claude or Codex hook schemas and do not add a static duplicate of the ODD core.
- S4 (verification): Capture RED then GREEN for native Package/SessionStart behavior and preserve existing startup behavior with paired fixtures or a base/candidate differential. Cover exact native manifest selection, skill and hook discovery, both modes, conversation-vs-inherited ID priority, malformed or failed input, and absence of other native hooks. Run the full suite and the installed `agy plugin validate --json` against a local candidate with an isolated home: expect one skill, one hook, no errors, and only the observed foreign `hooks/hooks.json` warning. Do not mask an unrelated warning. The deterministic repository suite must not require Antigravity to be installed.
