# Parent edit guard

Objective: in full delegation, block the parent's own `Edit`, `Write` and `NotebookEdit` calls on workspace files outside its closed write list, in code. Branch: `feature/parent-edit-guard`. Delivery: `ask-on-risk`. Runner: `bash tests/run.sh`.
Profile: `claude-gpt`.

## Specs

- S1 (user, verbatim): "si, dale", accepting the parent's proposal (verbatim): "`prompt-submit.py` mira el primer prompt de la sesión. Si trae el preámbulo de Orca o un `# Role:`, guarda el `session_id` como worker en `CLAUDE_PLUGIN_DATA`." and "cubre `Edit|Write|NotebookEdit` y solo actúa en modo full-delegation (leído con `profile.py`). No toca las llamadas con `agent_id` ni las de sesiones marcadas como worker. Para el parent: Si el archivo está dentro del workspace, se deniega, salvo `odd/tasks/*.md`. Si está en scratch o en el directorio temporal, se permite. Cualquier otro archivo fuera del workspace devuelve `permissionDecision: \"ask\"`."
- S2 (user, verbatim, same acceptance): "Lo que no cubre (habría que documentarlo): Escrituras del parent por `Bash` (`sed -i`, `>`). [...] Si Orca cambia su preámbulo, sus workers de Claude quedarían tratados como parent y se bloquearían. [...] No confirmé que el guard actúe en Code Mode."
- S3 (assumption, from the parent's live probes on 2026-11-23, Claude Code 2.1.330): PreToolUse stdin for a subagent's tool call carries non-empty `agent_id` and `agent_type`; the main thread's calls carry neither. `session_id` and the environment are identical in both, so neither can discriminate. Orca sets no worker-specific environment variable. Orca's dispatch prompt begins with `You are working inside Orca, a multi-agent IDE.` (Orca constant `ORCA_DISPATCH_STATUS_PREAMBLE_PREFIX`) and can also begin with `Please carry out this task from my Orca coordinator by following the brief I pasted below.` (`ORCA_DISPATCH_PROMPT_LEAD_LINE`). odd-flow worker specs start with `# Role: <role>` (`assets/spec-template.md`).
- S4 (assumption): worker marker. `scripts/prompt-submit.py` marks a session as a worker only on the first prompt it sees for that `session_id`, when the prompt, after leading whitespace, starts with either Orca line in S3, or its first non-empty line is `# Role: explore|write|verify|review|refute` (case-insensitive). It records every seen session so later prompts never mark it. State lives under `$CLAUDE_PLUGIN_DATA` with a filename-safe session id; without that variable or on a write error nothing is marked. Its existing mode restatement output and its never-block behavior stay unchanged.
- S5 (assumption): scope. The guard runs from `scripts/pre-tool-use.py`, with `hooks/hooks.json` matching `Edit|Write|NotebookEdit` besides `Agent|Task|Bash`. It acts only when `profile.py mode --json` (the call `prompt-submit.py` makes, with the payload's `session_id`) reports `full-delegation`; in organic mode, or when the mode cannot be resolved, it prints nothing. It never acts when `agent_id` is non-empty or the session is marked as a worker. The existing writer-launch surface guard for `Agent|Task|Bash` is unchanged.
- S6 (assumption): decision for a parent call. The target is `tool_input.file_path` (`Edit`, `Write`) or `tool_input.notebook_path` (`NotebookEdit`), resolved against the payload `cwd` when relative, with symlinks resolved. The workspace root is the Git top level of the payload `cwd`, else `CLAUDE_PROJECT_DIR`, else `cwd`. Inside the root: allowed only for `odd/tasks/*.md` directly under `odd/tasks`; otherwise deny. Outside the root: allowed silently under the system temp directories (`tempfile.gettempdir()`, `$TMPDIR`, `/tmp`, `/private/tmp`, each resolved); otherwise `ask`. A missing or non-string target path in full delegation denies.
- S7 (assumption): output. Deny and ask use the documented PreToolUse JSON (`hookSpecificOutput.permissionDecision` `deny` or `ask`, with `permissionDecisionReason`). The deny reason names the path and says that full delegation sends workspace changes to a bounded writer. The ask reason names the path and says the parent writes a file outside the workspace only after the user named it and confirmed the exact diff. An allowed call prints nothing and exits 0. An internal error after full delegation is established for a parent call denies; any other error prints nothing.
- S8 (assumption): docs. `skills/odd-flow/references/mode-full-delegation.md`, `skills/odd-flow/references/delegation.md`, `README.md`, `NOTES.md` (move the open item to Resolved) and the `hooks/hooks.json` description describe the guard and the limits in S2: `Bash` writes are not guarded; a changed Orca preamble without a `# Role:` first line would treat a Claude worker as the parent; whether the hook fires for Code Mode REPL calls is unverified.
